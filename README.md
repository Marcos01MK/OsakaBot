# 🌸 OsakaBot

![OsakaBot Banner](![OsakaBot Banner](assets/osakabot-banner.jpg))

Bot de Discord temático da **Osaka** (Azumanga Daioh), feito com carinho e muita personalidade.

Sistema completo de **tickets**, reações com áudios icônicos e eventos interativos.

---

## ✨ Features

### 🎫 Sistema de Tickets
- Painel interativo com menu de seleção
- Diferentes categorias de atendimento:
  - 🛠️ Suporte
  - 🛒 Compras
  - 🤝 Parcerias
  - ❓ Outros
  - 🚨 Denúncias
- Criação automática de canal privado
- Botão para fechar o ticket
- Embeds personalizados com visual da Osaka

### 🔊 Reações com Áudio
O bot responde com áudios clássicos quando alguém fala certas frases:

| Frase                    | Áudio                  |
|--------------------------|------------------------|
| `sata andagi`            | Sata Andagi            |
| `america ya`             | America Ya             |
| `omaigaa` / `oh my god`  | OMAIGAAAA              |
| `yamapikaya`             | Yamapikayaaaa          |
| `merry christmas`        | Merry Christmasuuuu    |
| `aaaaaaa`                | Aaaaaaa                |
| `heychu`                 | Heychu                 |

### 🦖 Evento do Saurus
Sistema de memória temporária. Se alguém falar sobre o Saurus estar doente ou ter morrido, a Osaka reage de forma contextual (com GIFs e mensagens).
